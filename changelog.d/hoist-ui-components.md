### New Features

* Added a `Chip` demo page to Components > General, showing hoist-react's new compact label, with a
  playground, filled, minimal and outlined styles for each intent and a custom color, sizes, toggle
  and removable chips, and chips in an inspector, a toolbar and a grid column.
* Added a `SortableList` demo page to Components > General, showing hoist-react's new
  drag-to-reorder list, with a playground, a horizontal list of chips, auto-scroll in a scrolling
  box, disabled items, and compact rows with an expandable detail and an Add row.
